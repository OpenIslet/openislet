# Contributing

This repository holds the OpenIslet blueprint: the design, the evidence behind it, the Idea Graveyard and the scripts that check them. It takes ideas, not pull requests.

## An idea for the blueprint

A weak spot, a better design choice, or a paper we missed. Send it as an Islet Improvement Proposal (IIP): [openislet.org/start](https://openislet.org/start) walks you through it with your own AI, and nothing needs installing. Please don't open a pull request or a plain issue for an idea.

What happens next, in public:

1. **Software checks it at once.** It posts the results on your IIP, which becomes an issue here.
2. **A person reviews each week's IIPs together,** with AI models helping, and posts the decision and its reason on the issue.
3. **If it improves the blueprint,** the next version includes it and names you. Credit comes in words, with no points or rankings. Locked versions never change, so your name stays.

## A problem with the files

If a file is wrong, a command fails, or the instructions in the README don't work from a clean checkout, open an issue with the form that offers. Say what you ran and what you saw.

We fix these ourselves rather than by pull request, because the files here are generated and checked as one set.

## House rules

- Plain English first, the scientist's detail underneath.
- Everything here is public. Please leave medical and personal details about yourself or anyone else out of IIPs and issues.
- Argue with the idea, not the person. If we remove something we say so in public, with the reason. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
