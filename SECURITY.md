# Security

This repository holds documents, data and scripts. It runs no service. The website and the connector are in [openislet/website](https://github.com/openislet/website), which has its own SECURITY.md.

## Reporting a problem

If you find something here that should not be public, for example a personal detail, a password or a key, or a script that does something unsafe, please email [hello@openislet.org](mailto:hello@openislet.org) with "Security" in the subject instead of opening a public issue. Say which file and line. We can't promise how quickly we will reply, but we do read what we are sent, and we remove such things at once.

## What this covers

The files in this repository. A mistake in the science, such as a wrong number or a missing paper, is not a security problem: send it as an IIP (see [CONTRIBUTING.md](CONTRIBUTING.md)).
