## 1. Purpose & Design Philosophy

This standalone operational playbook defines the exact bench-level execution protocol for the **Stage-0 Construct Pre-Pilot & `HIP-Core` Screening Architecture**, bridging the **8-run $2^3$ `Arm 1X` Locus-1 Component De-Confounding Factorial** (`24` clonal evaluations), the **Stage-0 Single-Variable & Architecture Challenger Panel** (`Arm 1B-CD47-C15G`, `Arm 1B-L1L2-Synonymous`, `Arm 1B-Sense-Terminator-Shield`, and `Locus 3 Scar-Free Dual-Promoter`), and the **36-run Two-Stage `HIP-Core` Fractional Factorial Design** (`25` distinct genotypes across `Stage 0` `Runs 01–16` [$B=0$] and `Stage 1` `Runs 17–36` [$B=1$], plus the optional `40-run` full-rank `29/29` 6-factor 2FI + quadratic `Q_3` bridge configuration [`Runs 37–40`]).
